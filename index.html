Cherche une carte par son nom français, récupère le JSON prêt à être chargé dans l'éditeur ygopro.org, et télécharge l'illustration officielle.

    ⬇️ Télécharger l'illustration (dessin seul)

    ⚠️ Notes sur la fiabilité du JSON

    Le format JSON a été reconstruit par rétro-ingénierie à partir d'un export réel (une carte Magie "Normal"). Les champs name, effect, atk, def, level et attribute (pour Magie/Piège) sont fiables. Les champs icon, type (texte entre crochets) et les valeurs liées aux monstres Pendule/Lien sont des estimations — vérifie-les dans l'éditeur et corrige si besoin. Si tu obtiens un export réel d'un monstre (SAVE CARD dans l'éditeur), ouvre une issue ou mets à jour script.js pour affiner le mapping.

    Données fournies par l'API YGOPRODeck. Merci de ne pas spammer l'API — une recherche = quelques requêtes.
